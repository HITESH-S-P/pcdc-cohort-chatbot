How this project works

This demo turns your natural-language cohort request into a GraphQL query for the Pediatric Cancer Data Commons (PCDC).

  • You type a cohort description (e.g. diagnosis, age, filters).
  • The backend LLM agent selects a tool (docs, generate, explain) and returns an answer — often a ```graphql block.
  • The UI renders that GraphQL in a “query card”, and you can optionally Test it against in-memory dummy data via /api/test-query.
  • Messages are sent via /api/chat (HTTP) with automatic fallback to Socket.IO if needed.
